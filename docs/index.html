The problem

Parents name children after what they hope for.

Hope, sky, compassion, faith. In Bangla these are words and names, so the same spelling can point to a person or to the very thing she was named for.

We give a model one sentence in which the word appears twice, once in each sense. It must label both occurrences with one of six cultural categories, then explain why.

  • Name
  • Concept
  • Emotion
  • Emotional State
  • Collective State
  • Spiritual

মায়া নামের মেয়েটিকে একাকী বসে কাঁদতে দেখে উপস্থিত সবার মনেই এক গভীর মায়া জেগে উঠল।

“Seeing the girl named Maya crying all alone, a deep compassionate tenderness awoke in everyone present.”

Stage 1

Building the dataset

A native Bangla speaker hand-picks words that genuinely live two lives. Three different LLMs then draft a sentence for each word, with the word used twice in two senses, plus an explanation and a cultural note.

Verification is round-robin: each model checks another model's output, never its own. Finally two native Bangla annotators review every instance and have the last word (Cohen's κ = 0.95).

Stage 2

        
Splitting the data

        
The instances are shuffled with a fixed seed and split three ways. Models learn on the training set, the validation set decides when training stops, and the test set stays unseen until the very end.

  • 10% validation
  • 12% held-out test

Stage 3

        
Three ways to ask

        
Zero-shot: just the instruction. Tested on six models: Qwen2.5-1.5B, Llama-3.2-3B, Ministral-3-3B, gemma-3-1b, TituLLM-1B and GPT-4o-mini.

        
Few-shot: three fixed solved examples, one from each major category, go before the question.

        
Cultural Chain-of-Thought (C-CoT): for each occurrence the model must write Argument A (why it could be a Name), Argument B (why it could be a concept or feeling), then a Decision. Arguing both sides first is what breaks the bias.

Stage 4

        
Reading the answer

        
Every model must end with a fixed FINAL: block. A parser pulls out the two labels and keeps the text before it as the model's explanation.

Stage 5

        
Teaching the reason: QLoRA-KD

        
Knowledge distillation. The verified explanations from large LLMs become the teacher's lesson. The small student model is trained to write the explanation first and then the labels, not just to output the labels.

        
Masked loss. Prompt tokens get the label -100 and are ignored. The loss is computed only on the explanation and the final labels.

        
QLoRA. The base model is frozen in 4-bit (NF4). Only small LoRA adapters are trained, so Wadapted = Wbase + B·A. It fits on a single 16 GB T4.

Stage 6

        
Scoring on unseen sentences

        
On the held-out test set, each prediction is scored on two tracks.

        
Labels. Exact Match means both labels are right. There's also average score, macro and micro F1, and the hallucination rate. The key one is Dominant-Bias: of the sentences whose gold answer contains a Name, the share where the model missed that Name.

        
Reasoning. The generated explanation is compared with the gold one using chrF and BERTScore, and is also rated by human judges and by an LLM judge.
