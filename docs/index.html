Unit 1 · Abstract

Course description

Many Bangla words are at once personal names and culturally loaded common nouns. Parents name their children after prized emotions, virtues and spiritual states, so a single surface form carries both an individuating reading and an abstract one.

This course introduces Culturally Entangled Homograph (CEH) disambiguation: given a Bangla sentence in which one word appears twice with two distinct readings, a model must assign each occurrence one of six culturally grounded categories, and justify the assignment.

We release a benchmark of 1,516 human-verified instances, show that open- and closed-source LLMs systematically default to the common-noun sense, and show that distilling cultural explanations into 1–3B models closes the gap.

Unit 2 · Motivation

The phenomenon

These are not accidental collisions like English bank. The two readings are linked on purpose: the name exists because the word means something a family hopes for. Tap a card to see both readings.

Instructor's note

An LLM that has mostly seen মায়া as an emotion will read every মায়া as an emotion, and so miss the person in the sentence. We call this dominant-meaning bias, and it is the main thing this benchmark measures.

Unit 3 · Problem definition

The task

Each instance is one sentence in which the target word occurs twice. The model labels token 1 and token 2 and explains why.

The six categories

  • Name a personal given name
  • Concept an abstract idea or object
  • Emotion a felt emotion
  • Emotional State a lasting inner condition
  • Collective State a shared or social condition
  • Spiritual a religious or mystical sense

Entanglement types

How it was built

  1. Step 1Word selection

    A native Bangla speaker hand-picked words with genuine dual readings.

  2. Step 2Multi-model generation

    Sentences and cultural explanations drafted by three complementary LLMs.

  3. Step 3Cross-model verification

    Round-robin checks, so no model audits its own output.

  4. Step 4Human verification

    Every instance reviewed by two native Bangla-speaking annotators, who have the final say.

Each instance carries token-level labels, a natural-language explanation for each occurrence, and a cultural-entanglement note. Splits: 78% train · 10% validation · 12% test.

Unit 5 · Approach

Methods

Four regimes, from no help to explicit reasoning supervision. Each one is scheduled like a week of the course.

  1. Week 1

    Zero-shot

    Instruction only. Shows the model's default reading of the word.

  2. Week 2

    Few-shot

    Worked examples in the prompt. Helps the format, barely helps the culture.

  3. Week 3

    Cultural CoT

    A contrastive chain-of-thought: argue for both readings before committing. No training required.

  4. Week 4

    QLoRA-KD

    Distil cultural explanations, not just labels, into 1–3B models with QLoRA on a single T4.

Unit 8 · Takeaways

Learning outcomes

By the end of this course, the student will be able to explain that:

  1. LLMs default to the dominant meaning. Open and closed models read the common-noun sense and overlook the person, with zero-shot bias up to 100%.
  2. Language is not culture. TituLLM, a Bangla-specific model, fails under every prompting regime. Language-specific pretraining alone does not bring cultural grounding.
  3. Arguing both sides helps. Cultural CoT cuts Qwen's bias from 63.46% to 2.88% with no training at all.
  4. Teach the why, not just the what. QLoRA-KD on cultural explanations takes 1–3B models to 82–88% EM with ≤4.2% bias, and turns the failing Bangla model into the strongest system (87.91%).

Grading rubric (evaluation metrics)

Label track

Exact Match · Average Score · Macro / Micro F1 · Hallucination rate · Dominant-Bias rate

Reasoning track

chrF · BERTScore against gold explanations · Human-as-a-Judge · LLM-as-a-Judge
